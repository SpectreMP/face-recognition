# Система распознавания лиц с голосовым приветствием

Клиент-серверная система на Python: клиент захватывает видео с камеры и отправляет кадры на сервер, сервер распознаёт лица (face_recognition/dlib), сравнивая их с эталонами, и возвращает команду приветствия вместе с **заранее синтезированным аудио** «Здравствуйте, {Имя}!». Клиент мгновенно воспроизводит его через колонки.

Обмен — ZeroMQ (PUSH/PULL для видео, PUB/SUB для команд). Управление эталонами — через веб-панель.

```
┌──────────────┐  кадры JPEG (PUSH→PULL :5555)   ┌───────────────────────────┐
│    Клиент    │ ──────────────────────────────► │          Сервер           │
│ камера +     │                                 │ распознавание лиц         │
│ динамик      │ ◄────────────────────────────── │ веб-панель   (Flask :8080)│
└──────────────┘  greet + WAV (SUB←PUB :5556)    │ кэш озвучки + TTS         │
                                                 └───────────────────────────┘
```

## Структура проекта

| Файл | Назначение |
|---|---|
| `server.py` | Сервер: приём кадров, распознавание, команды, запуск веб-панели |
| `client.py` | Клиент: захват видео, отправка кадров, воспроизведение приветствий |
| `webapp.py` | Веб-панель (список/добавление/удаление людей, статус озвучки) |
| `face_store.py` | Потокобезопасное хранилище эталонов (`known_faces`) |
| `voice_cache.py` | Кэш синтезированных фраз, TTS в изолированном субпроцессе |
| `throttle.py` | Антиспам: не чаще одного приветствия на человека за N секунд |
| `e2e_check.py` | Проверка полного цикла **без камеры** (отправляет фото как кадры) |
| `tests/` | Юнит- и интеграционные тесты (pytest) |
| `known_faces/` | Эталонные фото: `Имя.jpg`, `Имя_2.jpg`, … (одна папка = один человек) |
| `voice_cache/greetings/` | Готовые WAV-фразы (создаётся автоматически) |

## Быстрый старт (Docker)

```bash
docker compose up -d              # сервер + веб-панель на http://localhost:8080
docker compose logs -f server     # логи
```

Клиент с камерой и звуком хоста:

```bash
docker compose --profile client up -d client
```

> Клиенту пробрасываются `/dev/video0` и сокет PulseAudio (`/run/user/1000/pulse/native`).
> Если ваш UID ≠ 1000 — поправьте `user:` в `docker-compose.yml`.
> Для ALSA вместо PulseAudio в compose есть закомментированный вариант через `/dev/snd`.

Проверить цикл без камеры можно прямо внутри контейнера:

```bash
docker compose exec server python e2e_check.py --image known_faces/michael.jpg
docker compose exec server pytest        # тесты внутри контейнера
```

## Запуск без Docker

### Зависимости

```bash
pip install -r requirenments.txt
```

Linux: для офлайн-синтеза речи нужен движок TTS:

```bash
sudo apt install espeak-ng libespeak1      # pyttsx3 использует его автоматически
```


### Сервер

```bash
python server.py                # видео :5555, команды :5556, панель http://localhost:8080
```

При старте загружаются все эталоны из `known_faces/` и заранее синтезируются фразы для каждого имени. Окно предпросмотра открывается только без `--no-debug`; клавиши в нём: `q` — выход, `s` — сохранить аннотированный кадр (с `--save-debug`).

### Клиент

```bash
python client.py --server-ip <IP сервера>
# локально:
python client.py
```

Клиент подписан на свои команды по ID (по умолчанию hostname машины) и играет аудио первым доступным плеером: `paplay → aplay → ffplay → play`. Если плееров нет — приветствие пишется в лог, система продолжает работу.

## Веб-панель

Откройте `http://<IP сервера>:8080`:

1. Введите имя и выберите одно или несколько фото (лицо крупно, без искажений).
2. Нажмите «Добавить»: фото проверяется (если лицо не найдено — отказ), сохраняется в `known_faces/`, эмбеддинг сразу попадает в распознавание **без перезапуска сервера**, фраза озвучки синтезируется в фоне.
3. Бейдж на карточке показывает статус озвучки: `готова / синтезируется / нет / ошибка`. Кнопки: «переозвучить», «удалить».

Повторная загрузка фото того же имени добавляет ракурс (`Имя_2.jpg`, `Имя_3.jpg`, …) и повышает точность.

## Про кеширование фраз

Синтез выполняется **заранее**: при добавлении фото (или при старте сервера для уже известных людей). В момент распознавания остаётся только прочитать готовый WAV из кэша и передать клиенту (~миллисекунды). Фраза синтезируется одним куском — просодия лучше склейки «префикс»+«имя».

Деградация предусмотрена: если кэша нет (фраза ещё не успела синтезироваться), команда уходит с текстом без аудио, а синтез ставится в очередь — следующее приветствие будет уже с голосом.

Чтобы один человек не приветствовался каждый кадр, действует кулдаун: `--greet-cooldown`, по умолчанию 30 секунд.

## Параметры

### server.py

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--video-port` | 5555 | Приём видео (PULL) |
| `--command-port` | 5556 | Отправка команд (PUB) |
| `--known-faces-dir` | `known_faces` | Папка с эталонами |
| `--threshold` | 0.6 | Порог схожести (меньше = строже) |
| `--web-port` | 8080 | Порт веб-панели |
| `--no-web` | выкл | Отключить веб-панель |
| `--greet-cooldown` | 30.0 | Секунд между приветствиями одного человека |
| `--greet-template` | `Здравствуйте, {name}!` | Шаблон фразы ({name} — имя) |
| `--voice-cache-dir` | `voice_cache` | Папка кэша WAV |
| `--tts-rate` | авто | Скорость речи, слов в минуту |
| `--tts-voice` | авто | Подстрока имени голоса (напр. `ru` для espeak, `Irina` для SAPI5) |
| `--no-debug` | выкл | Без окна предпросмотра |
| `--save-debug` | выкл | Сохранять аннотированные кадры (`s` в окне) |

### client.py

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--server-ip` | 127.0.0.1 | IP сервера |
| `--video-port` | 5555 | Отправка видео (PUSH) |
| `--command-port` | 5556 | Приём команд (SUB) |
| `--camera-id` | 0 | Индекс камеры |
| `--fps` | 10 | Частота отправки кадров |
| `--client-id` | hostname | Идентификатор (адресат команд) |
| `--no-debug` | выкл | Не показывать окно камеры |
| `--no-audio` | выкл | Не проигрывать приветствия вслух |
| `--audio-player` | авто | Своя команда плеера, напр. `mpv --really-quiet` |

## Проверка и тесты

```bash
python -m pytest                          # юнит- и интеграционные тесты
python e2e_check.py --image known_faces/michael.jpg   # полный цикл без камеры
```

`e2e_check.py` отправляет изображение как серию кадров и слушает команды — удобно проверять сервер на машине без камеры. Полезные флаги: `--video-port`, `--command-port`, `--client-id`, `--frames`, `--timeout`.

## Частые проблемы

| Симптом | Решение |
|---|---|
| `Не найден аудиоплеер` в клиенте | Установите `pulseaudio-utils` или `alsa-utils`, либо задайте `--audio-player` |
| Озвучка «кракозябрами» (espeak читает русский английским голосом) | Запустите сервер с `--tts-voice ru` (в docker-compose уже включено) |
| Статус озвучки «ошибка» | Проверьте, что установлен espeak-ng/libespeak1; подробности в логах сервера; кнопка «переозвучить» повторяет попытку |
| Камера не открыта | Проверьте `--camera-id`; в контейнере — что `/dev/video0` проброшен |
| Приветствие приходит текстом, без аудио | Человек добавлен недавно — фраза ещё синтезируется; следующее через `--greet-cooldown` будет со звуком |
| Первая сборка docker идёт долго | Это компиляция dlib (~5 мин); дальше берётся из кэша слоёв |
